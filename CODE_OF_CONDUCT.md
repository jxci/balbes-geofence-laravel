# Code of Conduct

Минимальный набор правил для работы с этим пакетом:

- Не скатываемся в личные наезды, обсуждаем только код и архитектуру.
- В ишью и PR пишем по делу, без пустого флуда.
- Если есть конфликт — аргументированно и в рамках технической дискуссии.

Автор пакета оставляет за собой право закрывать обсуждения и отклонять PR, если они превращаются в мусорку.
